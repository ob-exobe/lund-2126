# Lund 2126

En forskningsförankrad framtidsvision för ett hållbart Lund om hundra år – välj Lunds väg 2026–2126 och se staden förändras.
A research-based vision of a sustainable Lund a hundred years from now.

**Öppna sajten:** https://ob-exobe.github.io/lund-2126/

Byggd med [sustainable-builder](https://github.com/fltman/sustainable-builder) (Anders Bjarby, motorn bakom Kalmar 2126).
Kartdata © OpenStreetMap contributors (ODbL) · Höjddata Copernicus DEM GLO-30 · Statistik från SCB, Kolada, SMHI, Region Skåne, Lunds universitet och Lunds kommun.
Modellen är ett tankeverktyg, inte en prognos; antaganden är markerade på sajten.
